vOps Day 19 — CI/CD Training
Project Name

devops-day19-cicd

Description

This repository was created as part of Day 19 DevOps training.

The purpose of this project is to practice Git, GitHub, automated testing, and CI/CD using GitHub Actions.

Application

The project contains a simple Python calculator.

The calculator provides four basic operations:

Addition
Subtraction
Multiplication
Division
Project Structure
devops-day19-cicd/
│
├── src/
│   ├── __init__.py
│   └── calculator.py
│
├── tests/
│   └── __init__.py
│
├── README.md
└── .gitignore

Calculator Functions

The application contains:

add()
subtract()
multiply()
divide()

Example
from src.calculator import add

result = add(10, 5)

print(result)


Output:

15
